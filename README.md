# 골든아워 발표 자료

팀 코드블루 · 실시간 응급실 병상과 이동 시간으로 응급실을 추천하는 웹 서비스 **골든아워** 발표 자료입니다.

| 파일 | 설명 |
|---|---|
| [`golden-hour.pptx`](golden-hour.pptx) | 발표 자료 원본 (21장, 슬라이드마다 발표 노트에 대본 포함) |
| [`golden-hour-preview.pdf`](golden-hour-preview.pdf) | 미리보기 PDF |
| [`build_deck.py`](build_deck.py) | 발표 자료 생성 스크립트 |

## 다운로드

파일을 누른 뒤 오른쪽 위 **Download raw file** 버튼을 누르면 받아집니다.

## 다시 만들기

```bash
pip install python-pptx
python3 build_deck.py
```

`build_deck.py`를 고친 뒤 실행하면 같은 폴더에 `golden-hour.pptx`가 새로 생깁니다. 폰트는 맑은 고딕 기준입니다.
